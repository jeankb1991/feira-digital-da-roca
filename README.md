# 🌾 Feira Digital da Roça
> Marketplace web para agricultura familiar — Projeto Integrador 3º Ano A

## 📋 Descrição
Plataforma que conecta produtores rurais e consumidores da região através de um catálogo digital com contato direto via WhatsApp.

## 🚀 Setup
1. Crie um projeto no Supabase (supabase.com).
2. No SQL Editor, execute o script em `supabase/schema.sql`.
3. Copie a Project URL e a chave anon public em **Project Settings → API**.
4. Cole as credenciais no arquivo `js/config.js`.
5. Hospede estaticamente no GitHub (basta enviar os arquivos da raiz sem automação) ou em qualquer servidor web.
